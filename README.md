# 2026 CPL Coding

C 语言程序设计（CPL）课程编程作业仓库，按作业批次分文件夹存放源代码。

## 项目简介

本仓库收录了 2026 年 CPL 课程我的编程作业的 C 语言源文件，
每个 `CPLworkN` 文件夹对应一次作业，文件命名规则为 `cpl{N}-{题号}.c`。

## 目录结构

```text
.
├── CPLwork2/          # 第 2 次作业
│   ├── cpl-2-1.c
│   ├── cpl-2-4.c
│   └── ...
├── CPLwork3/          # 第 3 次作业
│   ├── cpl3-1.c
│   └── ...
├── CPLwork4/          # 第 4 次作业
│   ├── cpl4-1.c
│   └── ...
└── README.md
```
